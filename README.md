## Features

Antiquities is a plugin based on [Relique](https://modrinth.com/plugin/relique/) and adds 9 Relics that fit well into vanilla.

### Items:

- Blaze Ember Ring: inflicts fire on target (requires either unarmed or an unenchanted tool)
- Echoing Circlet: causing blindness and glow effect on hit target
- Membrane Cowl: phantoms ignore you
- Piglin Signet: piglins ignore you
- and more...

The plugin also adds advancements for all the relics.
